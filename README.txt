# Perfect IT Solution Website

## Files
- `index.html` — homepage sections and navigation
- `style.css` — responsive dark-blue premium styling
- `script.js` — mobile menu, brand dropdown, year, WhatsApp enquiry form
- `assets/` — place your own logo or images here if needed

## Run locally
Open `index.html` in a browser.

## Publish on cPanel
Upload the contents of this folder to `public_html/`.

## Publish on GitHub Pages
Create a repository, upload `index.html`, `style.css`, `script.js` and the `assets` folder, then enable Pages from repository Settings.

Search/replace `9864440384`, `perfectitsolution531@gmail.com`, and `Sainamaina, Rupandehi, Nepal` in `index.html` if you want to change contact details.


## Add your ORIGINAL Perfect IT Solution logo (PNG)
1. Copy your original transparent PNG logo into the `assets` folder.
2. Rename it exactly: `perfect-it-solution-logo.png`
3. Refresh `index.html`. The logo will appear in the header and footer.
4. If the image file is missing, the website shows a text-based logo fallback.

Recommended logo file: transparent-background PNG, roughly 300x300 px or larger.
Use your exact original logo file if you want the authentic brand mark.


## Add branded logos (PNG)
Put each logo into `assets/brands/` using these exact file names: `hikvision.png`, `ezviz.png`, `hilook.png`, `dell.png`, `acer.png`, `hp.png`, `lenovo.png`, `canon-epson.png`, and `mikrotik-tplink.png`. Each brand card will show the PNG automatically. If a file is not present, a simple icon fallback remains visible.
